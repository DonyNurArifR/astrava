## Required design (implement exactly)
### A. Path security module (new): backend/app/workspace/path_security.py
- `class PathContainmentError(ValueError)`; `class ExecutionSetupError(RuntimeError)` (fail-closed signal for execution setup).
- `is_within(path, root) -> bool`: canonical, symlink-resolving (`Path.resolve()` on both, then `is_relative_to`). Never `startswith`.
- `safe_join(root, relative) -> Path`: reject any component equal to `.git` (compare case-insensitively after stripping trailing dots/spaces; a worktree's `.git` file/hooks must never be writable through an artifact name), reject non-str/empty, NUL or other control characters, absolute paths, Windows drive/UNC forms, any `..` component, backslash, more than 255 chars per component or 500 total; join; resolve (follows symlinks); require result within resolved root; raise PathContainmentError otherwise. Must reject a symlink located inside root that points outside root (or to a sibling like `<root>_evil`). Missing leaf allowed (for files to be created), but every existing ancestor is resolved.
- `validate_ref_name(name, kind="branch") -> str`: reject empty, leading `-`, whitespace/control chars, `..`, `@{`, `~ ^ : ? * [ \`, trailing `/` or `.lock` or `.`, double slashes, length > 100; allowlist of characters `[A-Za-z0-9._/-]`. (Defense against git option/refspec injection.)
- `validate_repo_path(raw) -> Path`: resolve; must exist, be a directory and be the top level of a git work tree (has `.git` dir or file); must be inside one of `settings.ALLOWED_REPO_ROOTS` (resolved); must NOT be inside, equal to, or contain `settings.ARTIFACT_STORAGE_PATH` or `settings.WORKTREE_STORAGE_PATH`; if `ALLOWED_REPO_ROOTS` is empty raise PathContainmentError saying repositories are not allowed until configured (fail closed). Returns the canonical resolved Path.
- `resolve_worktree_path(raw) -> Path`: resolve; must be inside `settings.WORKTREE_STORAGE_PATH`; raise PathContainmentError otherwise.
- `resolve_execution_work_dir(state) -> Path` (used by every graph node): project dir = `safe_join(settings.ARTIFACT_STORAGE_PATH, str(state.get("project_id","default")))`; if `state.get("worktree_path")`: it must pass `resolve_worktree_path` AND exist as a directory, else raise ExecutionSetupError (NEVER fall back to the project dir); if the state has `repo_path` but no `worktree_path`: raise ExecutionSetupError; otherwise return the project dir (created with mkdir parents) — projects with no repo keep working exactly as today.
- `write_text_contained(root, relative, text)`: re-run `safe_join` immediately before writing, resolve the PARENT directory and re-check it is within root, create parents, then open the final component with `os.open(..., O_WRONLY|O_CREAT|O_TRUNC|O_NOFOLLOW, 0o644)` so a symlink planted at the final component is refused. Used by `artifact_node` for every write. Document in the code that an agent running on the host can still race an intermediate directory (TOCTOU); that residual risk is closed only by sandboxing (M1.5-4), and it is recorded as such.
### B. Config

Document `ALLOWED_REPO_ROOTS` (JSON list) in README env table, .env.example (commented) and docs/SECURITY.md is the orchestrator's job — executor only reports.

### F. Worktree manager (merge target and refs)
- `create_worktree`: `validate_ref_name` on base_branch (if given) and require it to resolve (`git rev-parse --verify --end-of-options <ref>^{commit}`); if it does not resolve raise ExecutionSetupError (remove the silent `HEAD` fallback). `worktree_dir`, when passed, must pass `resolve_worktree_path` (inside WORKTREE_STORAGE_PATH). Existing idempotent re-create cleanup remains but only on a contained path.
- `merge_worktree(repo_path, branch_name, target_branch)`: validate both refs; `branch_name` must start with `astrava/exec-`; repo_path must pass `validate_repo_path`; read the current branch (`git symbolic-ref --short HEAD`); if it is not `target_branch` return `(False, "Repository is on '<x>' but merge target is '<target>'; refusing to merge")` WITHOUT touching anything; if the tracked working tree is dirty (`git status --porcelain --untracked-files=no` non-empty) return `(False, ...)`; never run `git checkout`/`switch` in the operator's repository. Merge using the full ref `refs/heads/<branch_name>` with `--no-ff --no-edit` and an explicit message. On success return `(True, output)`; the commit must land on `target_branch` only.
- Git hardening for EVERY git call made by `GitWorktreeManager._run_git` (and `VerificationEngine.collect_git_diff`): build a sanitized environment (keep only PATH, HOME, LANG, LC_*, USER, TMPDIR; drop every inherited `GIT_*` variable so ambient `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`, `GIT_SSH_COMMAND` cannot redirect operations), set `GIT_TERMINAL_PROMPT=0` and `GIT_CONFIG_NOSYSTEM=1`, and pass `-c core.hooksPath=/dev/null` so repository or worktree hooks planted by an agent never run during ASTRAVA's own add/commit/merge/worktree operations. Use full `refs/heads/...` names for branch arguments.
- `commit_changes(worktree_path, ...)`: validate the path with `resolve_worktree_path` before running git (defense in depth).
- `cleanup_worktree`: refuse (return False, log) any `worktree_path` not inside WORKTREE_STORAGE_PATH; never `rmtree` outside it; validate branch ref before `branch -D`.
- `get_diff`: validate/resolve `worktree_path` via `resolve_worktree_path`; validate base ref (fallback to HEAD stays ONLY for the read-only diff display when the ref does not exist).
### G. Projects and executions APIs
- `POST /projects` and `PATCH /projects/{id}`: when `repo_path` is provided (non-null) store `str(validate_repo_path(raw))` (canonical); when `base_branch` is provided run `validate_ref_name`; invalid -> HTTP 422 with the message (PathContainmentError text must not echo more than the supplied value). Explicit null clears repo_path. `GET /projects/{id}/scan`: re-validate `project.repo_path` via `validate_repo_path` (HTTP 400/422 on violation) before RepoScanner.
- `GET /executions/{id}/diff` and `POST /executions/{id}/merge`: validate `execution.worktree_path` with `resolve_worktree_path` (HTTP 400 on violation) and map a `(False, msg)` merge result to HTTP 422 as today.
